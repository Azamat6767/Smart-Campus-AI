# Smart Campus AI

Учебная веб-платформа для мониторинга инфраструктуры кампуса.

## Возможности
- Панель показателей и графики Chart.js.
- 12 демонстрационных аудиторий и 20 IoT-устройств.
- Поиск и фильтры по аудиториям и устройствам.
- Создание, редактирование, изменение статуса и удаление заявок.
- AI Analytics: пороговое обнаружение аномалий и рекомендации.
- Уведомления, светлая/тёмная тема и сохранение данных в localStorage.
- Адаптивный интерфейс для компьютеров и мобильных устройств.

## Запуск
Откройте `index.html` в браузере. Для лучшей совместимости можно запустить папку через VS Code Live Server. Для загрузки графиков требуется интернет-соединение, так как Chart.js подключается через CDN.

## Важно
Данные и роли являются демонстрационными. Это frontend-прототип, не подключённый к реальным датчикам и серверу аутентификации.

## Публикация
Загрузите все файлы в GitHub-репозиторий и включите GitHub Pages в Settings → Pages → Deploy from a branch → main → /(root).
